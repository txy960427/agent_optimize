# 读者动线与组件匹配审查

版本：v0.3 · 2026-11-25。审查对象为PRD、页面稿、SOP、组件方案和数据约定。方法为文档走查与模拟读者任务；不是对新网站的实际点击测试或用户研究。

## 1. 结论与验证层级

v0.2的问题不只在措辞：组件名与页面示意没有统一，主线入口偏多，阅读和操作的状态契约不够具体。本轮已修订规范，形成“短导览接图 → 连贯课程 → 真实案例 → 保留证据的判断 → 结果与下一步”的路径。

下表“已修订”表示文档中已给出处理规则。渲染、长内容、键盘操作、点击命中、滚动和实际保存仍待实现验证，不标为已通过。

## 3. 模拟读者：第一次学习

前提：读者理解业务问题，但尚未熟悉Trace与内部排查术语。

| 走到哪里 | 读者想知道/想做什么 | 修订后的体验 | 仍需验证 |
| --- | --- | --- | --- |
| 总纲开篇 | 为什么要学这个？ | 一段具体问题＋三条原则，不先问身份和路径 | 正文长度、标题是否清楚 |
| 向下看到地图 | 有哪些对象、彼此怎么配合？ | 分组与有意义的连线；五个Harness子对象直接可选 | 首屏密度、边标签和字号 |
| 悬浮/点击记忆 | 它是什么、做什么？ | 浮窗只显示定义/作用，入口待开放；模型入口可用 | 选择反馈、浮窗关闭、键盘顺序 |
| 继续学习 | 我要更深入看方法 | 进入正文而非回同一图；缺前置时提示先看运行材料 | 章节锚点和内容完整性 |
| 读到循环 | 四个环节为何会重复？ | 解释后紧接带回边的图，点击对照说明 | 图文距离、展开是否影响位置 |
| 试一道题 | 我的理解哪里不足？ | 原处反馈，能修改也能继续阅读 | 反馈高度变化和焦点 |

走查判断：主线不需要先掌握平台字段或填表，阅读顺序成立；图的实际密度与课程正文仍需逐页稿验证。

## 4. 模拟读者：带着案例排查

前提：读者有Session ID或问题关键词，想先查到实际记录。

| 走到哪里 | 下一步 | 反馈与控制 |
| --- | --- | --- |
| 全局真实排查 | 输入会话/关键词 | 最小所需字段，当前项目/时间可见 |
| 查询结果 | 预览并单选主要Trace | 来源与范围明确，错误/空/部分覆盖各有反馈 |
| 开始拆解 | 浏览映射，确认循环与环节 | 默认摘要，按需看原始树和修正；不逐条重建 |
| 定位 | 选择三种方法之一 | 控件匹配入口，原文与循环同步；切换不清空 |
| 想要帮助 | 可选LLM辅助定位 | 范围明确，一次调用，建议可跳原文，先待核对 |
| 核对输入 | 判断齐全/精准/一致 | 同一输入与引用，三个答案可见，不重复抄写 |
| 判断方向 | 沿问题推进，必要时返回 | 单一主提交，路径可回查，改上游提示复核 |
| 排查记录 | 看候选和下一步 | 摘要先行，详细依据可展开，尚未验证明确标记 |

走查判断：查询到结果、候选到人工确认、判断到下一步有明确转换；真正查询覆盖、映射正确性和保存恢复要用部署接口验证。

## 5. 模拟读者：实操中返回学习

1. 在“一致”项写了一半，不理解“前后有效信息”的标准。
2. 展开当前任务的简短说明；需要完整方法时进入课程，保留当前调查上下文。
3. 课程提供“返回当前排查”，不是重新开一份案例。返回原循环、环节、原文位置与未提交答案。
4. 如果源记录/映射在期间更新，显示受影响判断待复核；不静默沿用旧答案。
5. 如果辅助请求已发起，返回后读取同一请求状态，不自动再调用一次。
6. 修改判断，使用同一个主提交继续；保存失败时在原处处理，输入不丢失。

走查判断：恢复状态是正常动线的一部分，不能只靠“浏览器后退应该还在”。

## 6. 实现后的必要验证

- 阅读：中文行宽、标题与段落、图表相邻、长表/长消息、字体回退与200%缩放。
- 图：实际React Flow节点/边、关联高亮、浮窗及仅模型入口、默认连续播放/暂停、滚轮、触屏、键盘和窄屏详情。
- 动线：同页开篇到地图、学习继续、直接实操、返回学习、从课程回原调查。
- 状态：标签切换、来源滤镜、草稿/提交、保存失败、LLM请求/取消/失败、上游改动待复核。
- 数据：真查询与范围、Trace选择、循环/环节映射、原文引用、内容截断和证据不足。

本轮只做文档级验证，不用旧视觉样张替代这些检查。后续应针对新页面实现逐项记录实际结果。


## v0.5 实现后复核

前文为v0.3文档走查，保留其历史结论。本轮已用独立无头浏览器实际检查自己的本地原型：固定左目录、对象浮窗及仅模型入口、默认持续协作/暂停、下方分流、两栏拆解/判断、学习往返与刷新保存均已验证；桌面/平板/手机溢出检查通过。完整记录见[PROTOTYPE.md](PROTOTYPE.md)。这些前端结果不代表真实查询、内部埋点映射、完整课程审校或真实辅助服务已经验收。


## v0.6 全书动线复核

新增首页先回答范围与入口，前言再建立Agent概念，最后进入第1章调优方法；首页与总纲不再混为一页。第0—6章目录在页面之间保持一致，缺材料章节没有空白链接。三个前言情境、组件查看、播放控制与刷新锚点已在独立无头浏览器中验证；原排查完整路径继续通过。窄屏架构仅局部滚动，整页无横向溢出。演示是科普示例，不能被解释为真实排查或实际LLM执行。

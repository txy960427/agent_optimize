当前完整定位见[POSITIONING.md](POSITIONING.md)，当前两版首页见[HOME-V12.md](HOME-V12.md)。指南为医疗设备智能体提供调优方向、技术方法与内部案例指导。首页2展示完整问题驱动闭环，前言原文与理解见[读取档案](PREFACE-READING-NOTES.md)。前言确立四项目标、三种使用路径与环境归因边界；架构知识与实操都是其中的内容。

版本：v0.9 · 2026-11-25。依据实际前言校正全链路指南定位，保留两版首页，调优总纲独立为第1章，七章结构与内容状态统一到固定目录；实操已接入本地Langfuse实际导出，实时服务接入另行核对，见[REAL-DATA-WORKSPACE.md](REAL-DATA-WORKSPACE.md)。当前视觉以[VISUAL-RESET.md](VISUAL-RESET.md)及新原型为准。

## 当前实施阶段：实际导出驱动的本地工作台

当前可运行项目分为[前端 web/](../../web/README.md)和[数据接口 server/](../../server/README.md)。实操通过本地只读接口分页读取data目录中的实际Langfuse导出，人工答案与引用保存在本机；不再使用fixture。LLM尚未配置，按钮禁用，不提供预设意见。当前没有连接内网实时API，导出与实时查询范围需区分。

原型说明、已覆盖范围与验证记录见 [PROTOTYPE.md](PROTOTYPE.md)。旧预览样张已于 2026-11-26 移出仓库，不再作为当前原型入口。

## 已确认的方向

- 面向研发与产品混合受众；用户已要求替换初版单调配色，现采用中性蓝灰界面与语义分组色；深色架构科普置于前言，总纲回路图为浅色。
- 先完整设计《Agent 调优技术总纲》，保留通往《模型优化》的课程入口。
- 所有对象均可悬浮或点击查看定义与作用；说明采用浮窗，不占永久右栏。浮窗只保留一个小入口，目前仅“模型”的“进入模型优化”可用，跳至已有模型课程；其余对象显示禁用的“对应内容待开放”。不在导览浮窗加入证据、检查项或诊断建议。
- 全站使用同一固定左目录：首页1、首页2、第0—6章、真实排查与我的排查记录。前言在调优总纲之前，总纲内部再展开对象地图和方法子目录；模型是第3章。目录内容不随页面替换，只更新当前项和展开层级。顶部只保留品牌与原型状态；工作台使用当前阶段切换与就近主操作。窄屏将同一目录收为抽屉。
- 站点首页展示完整章节、从前言开始与实操入口。第1章地图右侧放三条经验，阅读与实操放地图下方；协作默认连续播放，可暂停。实操拆解为结构/原文两栏，判断为证据/任务两栏。
- 地图以可交互图组件作为主呈现。受众、设计尺寸与提醒等保留在规范里，不作为页面文案。
- 实操使用真实 Langfuse API 数据，用户可通过 Session ID 或关键词找到案例；主要排查操作在本站完成。
- 用户作出判断；每个判断点可以主动调用一次 LLM 辅助。LLM 意见不自动替用户提交判断。
- 需要覆盖选 Trace、拆步骤、三种方法定位、拆模型上下文、走决策图、形成候选优化对象，以及中途补信息和修改判断。

## 本次修订的产品建议

- 开篇与地图同页，减少入口；正文保持连贯，图表紧邻解释。关系用图、对照用表、记录用循环树、判断用表单，按信息选组件。
- 学习与实操往返、切换定位方法/消息视图，保留位置与输入。三标准共用输入和引用，结果先候选与下一步、后长记录。
- 按原稿 p7 图4，Trace 外层为①请求接收与⑥输出交付，Agent Loop 内重复②–⑤。主定位步骤采用一次循环，UI称“循环1、循环2……”，再展开环节和原始记录。
- 三种定位方法都可按需使用 LLM 辅助，默认不调用；优先帮助语义比较和上下游回查。程序负责实际检索/状态筛选，用户确认候选。定位辅助与后续三标准/决策辅助分开记录。

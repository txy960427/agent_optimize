# 全局界面与表格细节

当前全局尺寸、颜色与首页构图以[LAYOUT-AUDIT.md](LAYOUT-AUDIT.md)为准（2026-11-26后续修订）。工具与打印交互继续遵循本文，布局已集中到`layout.css`；首页由`home-focus.css`和`home-sop.css`维护。

2026-11-26。按用户参考图中圈出的品牌/工具区、位置标签、圆角主视觉与表格区域进行细节修订，沿用本站内容与交互。

## 图标与顶部工具

品牌图标为书页与分支路径的代码原生矢量，使用既有蓝色与琥珀色。网页favicon采用同一图形；侧栏、面包屑与顶部工具的图标维持统一线宽。

右上角增加章节查找与打印入口，保留本地预览说明。没有学习完成率数据时不显示进度条。查找索引涵盖章节、前言子节、课程主题/段落关键词和实际排查入口：

- Ctrl/Cmd+K打开，Enter进入首个可读结果，方向键定位结果，Esc关闭。
- 输入可包含中文与技术词；忽略英文大小写和名称中多余空格。标题匹配优先，待补齐章节可被找到但不能跳转。
- 结果进入对应页面或H2/H3锚点；关闭查找弹窗时不把焦点从目标标题抢回顶部按钮。普通取消仍恢复触发按钮焦点。
- 无结果明确提示；不会搜索或上传内部Trace原文。

打印调用浏览器原生打印，可选择保存PDF。纸面隐藏顶部/侧栏/局部目录；协作图使用其文字责任表，打印完成恢复文字表的先前折叠状态。手机保留查找入口与原目录抽屉，极窄屏收起打印。

## 面包屑与首页

共享`Breadcrumb`改为具备当前位置语义的导航，浅蓝底、小圆角和当前章节深色文字帮助识别所在章节。它维持紧凑尺寸，不承担主要标题角色。

首页演示采用开放式左文右窗口构图，白色窗口、浅工具栏、细线阶段标记；已取消跨两栏的大色块与深色外框。两版首页和实操默认折叠目录，左侧半圆柄覆盖展开。原有发现问题、定位对象、专项改进、验证、沉淀更新的内容与播放行为保持，细则见LAYOUT-AUDIT。

## 表格系统

课程说明表、前言表、案例列表与已有数据表共享颜色令牌：

| 角色 | 颜色 |
| --- | --- |
| 表头背景 | `#E8EDFA` |
| 表头文字 | `#273C67` |
| 分隔线 | `#D7DEEA` |
| 间隔行 | `#F7F9FC` |
| 悬停行 | `#EDF1FF` |
| 当前选中Trace | `#E0E6FF` |

阅读表格使用完整边框与10px圆角，表头/短字段保持单行。实操表格保留原列宽、固定表头、选择控件和响应式规则。选中行优先于间隔行/悬停底色；错误、证据和业务状态的语义色保持独立。窄屏表格仍仅在自身区域滚动。

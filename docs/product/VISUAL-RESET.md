# 原型视觉与布局调整（当前 v0.6）

日期：2026-11-25。依据用户对第一版单调、松散、图示不突出、检索占位过大的反馈，替换原型视觉基调；功能与人工判断原则继续沿用PRD。

## 方向

将技术学习和观测工作台组织成同一产品：中性蓝灰界面，紧凑导航；对象关系使用语义分组色；Agent Loop作为有控制的动态讲解；检索围绕结果与详情展开。

- 模型：紫色；Harness：蓝色；环境/信息准备：青绿；执行与支撑：琥珀。
- 深色区域用于第0章前言的架构科普，帮助建立Agent运行认知；第1章六环节随文图采用浅色，全站不切为深色。
- 主正文和任务答案保持足够字级。紧凑来自对齐、分组和减少无用容器，不来自把文字缩小。

## 具体替换

| 区域 | 第一版的问题 | 当前实现 |
| --- | --- | --- |
| 指南首页 | 总纲被当成整个网站，缺少全书层级 | 新增指南封面与七章总导览，主阅读入口进入前言 |
| 第1章导览 | 大标题和原则占用过多空间，关系图弱 | 对象地图移至第1章，经验在右，阅读/实操在下 |
| 对象地图 | 全绿分组与静态箭头，不易分清角色 | React Flow语义分组色、带标签箭头、默认连续协作动画、可暂停；所有对象可看浮窗，仅模型入口开放 |
| Agent Loop | 横向小流程图被缩小，循环不明显 | 四环节2×2回路、外层接收/交付、播放/暂停/逐步/重置，说明与示例随环节切换 |
| 课程目录 | 名称长、缩进与大间距不统一 | 简短标签、33px左右行高、统一对齐，不再用大段编号与多层留白 |
| 案例入口 | 搜索表单占据上方大块区域，按钮在下方 | 查询/筛选/开始在紧凑工具栏；默认收起高级字段；模拟场景为一行轻量入口 |
| 案例结果 | 松散列表、详情与操作不集中 | 主从布局：左侧紧凑表格，右侧Trace预览与对照；开始按钮首屏可见 |
| 排查工作台 | 三个内部栏位挤占阅读宽度 | 拆解阶段为运行结构/原文两栏，确认在上方；后续为证据/任务两栏，循环树按需浮层打开 |

## 参考与复用

- [LangChain技术文档](https://docs.langchain.com/langsmith/observability-quickstart)：课程导航、正文与局部交互的熟悉组织方式。
- [Linear文档](https://linear.app/docs)：简短分组目录和紧凑层级。
- [Langfuse Sessions](https://langfuse.com/docs/observability/features/sessions)：会话内定位、原文和Trace侧面查看的交互关系。
- [React Flow动态边示例](https://reactflow.dev/examples/edges/animating-edges)：自定义SVG路径上的信号动画。
- [Motion for React](https://motion.dev/docs/react)：用户选择后的布局/状态过渡。

没有复制上述产品的商标或把其云端界面冒充内部部署。参考组织方式和组件能力，内容与SOP保留本项目语义。

## 动画边界

按用户确认，对象协作默认持续播放，可暂停/继续；动画不覆盖用户选择或浮窗。Agent Loop仍主动播放，可暂停、逐步与重置。阅读入口可用轻微箭头动效。减少动态效果模式默认暂停协作并关闭非必要动效；所有演示不自动回答或写入判断。

## 验证

原有完整排查交互脚本继续验证。新增redesign-check检查图的关系标签、播放/暂停、循环说明联动、工具栏高度、开始入口、主从布局和窄屏溢出。以实际截图复核字级与信息密度，不能只凭构建通过判断观感。


## v0.6 首页与前言

借鉴[阿里白皮书首页](https://aliyun.github.io/ai-agent-handbook/)的整本导览结构，保留本站蓝灰与语义分组色。首页为指南标题、书封视觉、从前言开始和全书目录；原对象地图归入第1章，不再承担整个网站首页。固定左目录包含第0—6章及实操。

前言用三个示例情境播放Agent架构，支持暂停、逐步、重置、组件查看和完整结构恢复；结束与反馈分支从外围布线，默认视口同时容纳连线与节点。总纲浅色回路专注六环节与运行记录。详见[GUIDE-STRUCTURE.md](GUIDE-STRUCTURE.md)。

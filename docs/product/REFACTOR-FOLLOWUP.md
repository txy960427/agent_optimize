# 重构后的遗留问题修复

2026-11-26。基于当前`web/src/app`、`pages`、`components`、`domain`、`api`、`styles`以及根目录`server`、`shared`结构修复，沿用最后加载的`styles/layout.css`布局约定。没有恢复旧源码目录或覆盖重构中的文件迁移。

## 已保留并复核的总纲功能

独立“优化对象”课程已经去重，总览与其他节处于同一目录层级；旧链接回到总览地图。地图默认显示完整对象，三类跨对象支撑会强调相应对象与虚线；决策图可逐项判断、回退、查看材料依据及演示设备号情境。原始依据见[OUTLINE-CORE-V13.md](OUTLINE-CORE-V13.md)。

## 本轮修复

| 遗留问题 | 修复与代码归属 |
| --- | --- |
| 目录与搜索反向导入课程页面，内容数据与渲染耦合；删除对象课程后仍有无用参数/导出 | 课程正文与练习移入`domain/lessons.ts`，`app/Sidebar`、`GuideTools`和课程页共同读取；清理课程页遗留的地图参数、组件别名和无用导入 |
| 对象选择同时走按下、点击、React Flow回调等多条路径；拖动可能当作选择 | `pages/guide/ObjectMapCore.tsx`以一次按下/松开配对确认选择，取消与超过6px的移动不选择。保留键盘与辅助技术激活；焦点移出节点会解除悬浮强调 |
| 页面切到后台后定时器可能继续推进，动画仍流动 | `components/usePlaybackVisibility.ts`统一监听页面可见性与组件交集，地图和决策演示不可见时停计时及流动效果 |
| 运行中切换减少动态效果，按钮与动画状态可能不同步 | 同一公共Hook通过`useSyncExternalStore`订阅媒体查询，当前偏好变化即生效 |
| 决策示例暂停后重新播放会清空路线；暂停只停答案、不停流线 | `pages/learn/DecisionExplorer.tsx`保留教学播放位置，恢复从下一判断继续；暂停同时停止流线，播放结束保留静态结果，重置/改答清理教学进度 |
| 决策图另外维护了一份条件分支，可能与实际工作台漂移 | `domain/data.ts`统一提供`decisionBranches`和`decisionTarget`；图形只决定连接端口，条件与真实调查共用 |
| 仅遍历现有输入字段，空或不完整三标准记录可能被判全部通过 | 显式核对齐全、精准、一致三项；缺任一项保持待补。有“不满足”时仍可核对Harness，保留其他未决项 |
| 不支持“不适用”的节点可能把该答案当作通过 | 只有规则声明了该条件才能跳过；其他节点保持待补，不生成候选 |
| 阅读回归检查强制所有页面共享绝对左边距，并要求末尾锚点始终靠上 | 改为检查标题与自身正文对齐、共同字号与垂直位置；页尾已滚到底时，要求标题可见且不被顶栏遮挡。保留新居中布局及完整焦点/目录校验 |
| 部署说明遗漏新结构的`shared`目录 | 根README补齐运行目录与复制清单；该目录是前后端的运行依赖 |

真实调查继续使用实际导出、人工答案及原来的本机存储空间。教学演示不会写入调查；查看候选节点不会自动形成当前案例的候选。

## 检查入口

在`web`中运行：

- `npm run test:unit`：11项检查，包含输入不完整、八条终点路线、证据不足与不适用边界。
- `npm run build`：类型检查与构建。
- `npm run test:guide`：对象地图、八条决策路线、示例暂停/继续、键盘与320—1920px布局。
- `npm run test:playback`：按下/松开、拖动不误选、后台暂停与恢复、实时减少动态效果。
- `npm run test:reading`：9个阅读页面、42个小节链接、重复点击、刷新/返回与目录滚动。
- `npm run test:e2e`：实际导出工作台的拆解、定位、输入核对、人工决策、引用、保存恢复与映射修正。

页面检查使用独立无头Edge，只访问本地站点。当前完整说明、部署步骤和目录职责分别见根[README](../../README.md)、[组件选型](COMPONENTS.md)与[实际工作台](REAL-DATA-WORKSPACE.md)。

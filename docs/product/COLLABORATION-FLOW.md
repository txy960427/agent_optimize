# 内部协作SOP交互图

2026-11-25。依据用户提供的原图，用项目已安装的React Flow还原；不是另建一套工单系统。原图保留为对照，旧Agent运行原理演示继续单独位于前言补充中。

## 原图中的协作关系

开发者携带问题描述与Langfuse追踪码，评审者携带产品/架构评审问题清单，测试者携带测试报告与Badcase记录。三入口共同汇入小U主owner与AIC智能体团队；分析界定后按运行环境、Harness、模型问题分流。各责任团队解决后反馈至共同分析节点，形成闭环。

| 问题层级 | 定位对象 | 责任团队 |
| --- | --- | --- |
| 运行环境 | 容器、沙箱、工作流运行环境 | 工程开发团队 |
| 运行环境 | Skills挂载、MCP工具、API等 | 应用开发团队 |
| Harness | 基线框架 | 智能体框架团队 |
| Harness | 安全护栏、个性化等算法特性插件 | AIC智能体团队 |
| 模型 | LLM基座模型 | AIC大模型团队 |
| 模型 | ASR/TTS语音小模型 | AIC大模型团队 |
| 模型 | Embedding模型 | AIC大模型团队 |
| 模型 | 意图、快速决策等专用小模型 | AIC智能体团队 |

以上按照原图映射，没有用一般技术常识重分责任；例如Skills挂载/MCP/API仍处于原图运行环境分支。主owner具体组织归属在原图未清晰确定，因此图中只保留“小U主owner + AIC智能体团队”。

## 图形与交互

- 全图共25个节点：3种发现入口、3份上报材料、1个共同界定节点、3类问题、8类定位对象、6处责任团队及1个反馈节点。两处AIC智能体团队在图中对应不同分支，共用同一职责名称。
- 顶部选择问题来源与分配路线，或点击图中入口、分类、对象和责任团队。选中路线完整高亮；未选分支保持可读，便于对照。
- 当前路线依次经过发现、上报、共同界定、问题类别、具体对象、责任团队和反馈。流动连线说明交接，下方文字解释当前步骤。
- 默认播放；用户改变路线或点击节点即暂停。支持暂停/继续、下一步、重置。图离开视口停止推进，减少动态效果默认暂停且关闭流动信号。
- 静态阶段栏只说明五类协作职责，不作为新的顶部数字步骤导航。反馈线从责任团队汇合，回到共同分析节点。
- 小屏保持固定可读字号，通过画布局部水平滚动查看；不缩小整幅图，也不让整页横向溢出。提供责任分配文字版与原图对照。
- 所有分支为可命名按钮，支持键盘。图不自动提交真实判断、分配工单、调用Langfuse或LLM。
